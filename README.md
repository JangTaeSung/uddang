# Uddang 혈관도

상지 혈관을 고르고, 구부리고, 색·직경·표식을 남기는 웹 편집기입니다.

화면 왼쪽이 오른팔, 오른쪽이 왼팔이고, 위쪽이 요골(엄지) 쪽입니다. 편집 내용은 그 브라우저에만 저장됩니다.

## 친구가 브라우저로 열기

이 저장소는 공개입니다. GitHub Pages를 한 번 켜면 아래 주소로 접속합니다.

1. 저장소 **Settings → Pages**
2. Branch를 `cursor/vessel-map-share-a7d4`, Folder를 `/ (root)`로 저장
3. 1–2분 뒤 https://jangtaesung.github.io/uddang/

메인으로 합친 뒤에는 Pages 브랜치를 `main`으로 바꾸면 같은 주소가 유지됩니다.

## 하는 일

- 혈관은 꺼진 상태로 시작합니다. 왼쪽 체크를 켜면 도식에 나타나고, 이름을 누르면 편집합니다.
- 직경(mm)은 선 굵기와 목록에 반영됩니다.
- 색, 표시 여부, Considerable / Borderline 스타일을 바꿀 수 있습니다.
- 표식: 보더라인, 혈전(Th), 굽힘, 분지(Br). 클릭으로 놓고, 끌어 옮기고, 메모를 적습니다.
- 되돌리기, 다시 실행, 점 추가·삭제, PNG/SVG 저장.

## 윤곽 그림

기본 몸 그림은 `assets/body-outline.png` 입니다. 다른 그림을 올리려면 **윤곽 이미지**를 쓰고, **기본 윤곽**으로 되돌립니다.

## 로컬에서 열기

```bash
python3 -m http.server 8765
```

브라우저에서 `http://127.0.0.1:8765` 를 엽니다.
